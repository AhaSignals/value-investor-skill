# Value Investor Skill v0.1.0

Is this stock worth its price?

This first open-source release combines an AI research skill with dependency-free Python tools for scenario values, price-implied assumptions and evidence revisions.

Try the fictional $40-stock demo: the same price fits different assumptions; when launch-timing evidence is withdrawn, dependent values become unavailable and the original research remains in the ledger.

Included: English/Chinese README, installation helper, fictional clinical and merger inputs, local reports, tested state transitions, optional SEC filing-index discovery and a portable MIT-licensed release archive.

Python 3.9+. The offline demo needs no pip packages, paid data or model calls. Real research uses your AI host and reviewed sources; its costs and permissions apply.

This release does not estimate calibrated probabilities, establish a cost-adjusted investment edge or execute trades. Price-matching weights are conditional arithmetic, not event forecasts.
