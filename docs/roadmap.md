# Roadmap

The first release answers a small, testable question: given reviewed scenarios and dated evidence, what does the price require, and which numbers must be withheld when support changes?

## Next: reduce the work needed to start

- A guided input builder that shows missing evidence before it asks for valuation assumptions.
- Primary-source adapters with explicit publication, observation, version and licensing fields. Keep network access opt-in.
- Examples from real public filings, with dates and redistribution review, clearly separated from fictional fixtures.
- More useful evidence diffs: show the exact claim and dependent assumptions needing review.

## Then: earn stronger conclusions

- Prospectively register event definitions, resolution rules and forecasts before outcomes.
- Evaluate calibration against simple reference-class baselines, with abstention and missingness visible.
- Add sector-specific economics only when inputs and assumptions can be reviewed.
- Preserve held-out cases and publish failures. Passing code tests is not validation of investment performance.

AhaSignals supplies the research discipline and can use this open format for auditable research. This repository is independently usable: no AhaSignals login, private API or paid subscription is required. There is no live integration or automatic upload in v0.1.0.

These are research priorities, not dated delivery commitments. A validated probability or cost-adjusted investment gap must not appear merely because a feature is on the roadmap.
