CLI output, generated reports, input keys and detailed specifications remain English. The skill asks the AI host to match the user's language; this is an instruction, not a guarantee of language quality across every model.

The five additional guides were prepared with AI assistance. They have not received independent native-speaker review. Corrections are welcome through [the experience form](https://github.com/AhaSignals/value-investor-skill/issues/new?template=experience.yml).

When translating, preserve the numerical example and these distinctions: scenario values are assumptions; price-matching weights are not event probabilities; publication and observation times differ; withdrawn sources invalidate dependent estimates; no calibrated probabilities, investment recommendations or return claims are provided. Do not translate code identifiers, paths or status constants.
